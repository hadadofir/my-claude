# Tag Taxonomy

Tags for cross-referencing topics. Use consistent tags for discoverability.

## Categories

### Domain Tags
- `technical` - Software, programming, tools
- `scientific` - Research, experiments, theories
- `business` - Strategy, markets, organizations
- `general` - Broad knowledge topics

### Depth Tags
- `overview` - Surface-level understanding
- `intermediate` - Working knowledge
- `deep-dive` - Expert-level exploration

### Status Tags
- `in-progress` - Currently researching
- `complete` - Research finished
- `needs-update` - Information may be stale

### Type Tags
- `concept` - Abstract ideas or theories
- `skill` - How-to knowledge
- `tool` - Specific software/technology
- `comparison` - Evaluating alternatives
- `history` - Historical context

## Tag Usage

Format: `#tag-name` in topic README.md files

Example:
```markdown
Tags: #technical #deep-dive #tool #complete
```
