# Deep Dive Generation Prompt

```
Generate a comprehensive deep dive for [TOPIC] using the template at _templates/deep_dive.md.

INPUT:
- All research notes from sources/
- Existing summary if available

REQUIREMENTS:
- Thorough coverage of all major aspects
- Historical context and background
- Multiple perspectives including contrarian views
- Practical applications with examples
- Honest assessment of limitations
- Clear source attribution
- Areas of uncertainty acknowledged

STRUCTURE:
- Follow template sections
- Use headers for navigation
- Include code/diagrams where helpful
- Link to related topics

TONE:
- Educational but not condescending
- Acknowledge complexity without being confusing
- Distinguish fact from interpretation

OUTPUT: Save to outputs/deep_dive.md
```
