# Summary Generation Prompt

```
Generate a summary for [TOPIC] using the template at _templates/summary.md.

INPUT:
- Research notes from sources/ folder
- Any existing analysis

REQUIREMENTS:
- Maximum 1 page when rendered
- 3-5 key takeaways, prioritized by importance
- Clear "What It Is" explanation a beginner could understand
- Honest "Confidence" rating
- At least one common misconception addressed
- Links to sources

TONE:
- Concise and direct
- No filler or hedging language
- Actionable where possible

OUTPUT: Save to outputs/summary.md
```
