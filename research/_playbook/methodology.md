# Research Methodology

Core principles and process for effective research.

## Research Phases

### 1. Scoping
- Define the question clearly
- Identify what success looks like
- Set boundaries (what's in/out of scope)
- Estimate depth needed (overview vs deep-dive)

### 2. Discovery
- Broad initial search to map the landscape
- Identify key sources, experts, and terminology
- Note competing perspectives or schools of thought
- Flag areas of controversy or uncertainty

### 3. Deep Gathering
- Read primary sources, not just summaries
- Collect diverse perspectives
- Document source credibility
- Save raw materials in `sources/`

### 4. Analysis
- Synthesize findings into coherent understanding
- Identify patterns and key insights
- Note gaps in knowledge
- Form conclusions with appropriate confidence levels

### 5. Validation
- Run critic sub-agent to challenge findings
- Check for confirmation bias
- Verify claims against multiple sources
- Test understanding by explaining simply

### 6. Output Generation
- Create materials using `_templates/`
- Tailor format to learning goal
- Include confidence levels and caveats
- Link to sources

### 7. Integration
- Update `_meta/index.md` with new topic
- Add relevant tags
- Note connections to other topics
- Update `_meta/insights.md` if cross-topic patterns emerge

## Principles

- **Source hierarchy**: Primary > Secondary > Tertiary
- **Recency matters**: Check publication dates, prefer recent for fast-moving fields
- **Epistemic humility**: Note confidence levels, distinguish fact from interpretation
- **Falsifiability**: Actively seek disconfirming evidence
- **Simplicity**: If you can't explain it simply, you don't understand it well enough
