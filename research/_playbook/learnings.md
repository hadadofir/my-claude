## Topic-Specific Insights

### Technical Topics
- Check official documentation first before community sources
- Look for "awesome-X" lists for curated resources
- GitHub issues often contain real-world edge cases

### Scientific Topics
- Start with review papers for landscape overview
- Check citation count but also recency
- Look for meta-analyses when available

### Business/Strategy Topics
- Primary sources (earnings calls, filings) beat commentary
- Consider incentives of information sources
- Historical context often crucial
